# Urban Air Quality Trend Analysis Across Indian Metro Cities

## Project Overview

This project analyzes air quality trends across major Indian metro cities using Python, data analysis, and visualization techniques.

## Objectives

* Analyze AQI trends across cities
* Compare pollutant concentrations
* Identify pollution patterns and insights

## Tools and Technologies

* Python
* Pandas
* Matplotlib
* Power BI
* Streamlit

## Project Files

* `air5.py` : Main project code
* `urban_aqi_powerbi_dashboard.html` : Interactive dashboard
* `.jpg files` : Visualization outputs
